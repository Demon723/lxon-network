Swap is offline

The LXON swap interface is not available right now, and it is not a connectivity problem. Chain 724 was restarted on 2026-11-03 from its original genesis file on a fresh, empty data volume, after the previous node and its database were lost. The chain identity is the same — block 0 is still the same hash and it is still sealing blocks every five seconds — but everything created in blocks 1 to 242,493 is gone, including the token, the wrapped token, both pools and the router this page traded against.

What that means for a swap: the eight chain-724 contracts still hardcoded in the swap interface currently have no code deployed at them. There is no liquidity to route through and no token to move. Publishing the trading form against those addresses would invite you to sign approvals and send transactions to contracts that do not exist, so the page is withdrawn instead.

The swap page also names 0xbDC32d8Ca8Ce805E0654e7A7d0DD1eE0A21D4a95 and 0x7A3c0C34f157EfDD3E4913c5224C15E645469093. Those are Polygon (chain 137) contracts and are expected to have no code on 724; they are not part of what was lost, and they are deliberately not counted as evidence above.

Nothing here is estimated. The node answers at eth_chainId 0x2d4 and is producing blocks; it is the chain-724 contracts that are absent.

What would bring the swap back: redeploying the token, WETH, the pair and the router on chain 724 and funding a pool. Until then there is no honest price to quote and no route to show, so the figures on this site's other pages say not read rather than guessing — that behaviour is deliberate and is how the pages were built.
