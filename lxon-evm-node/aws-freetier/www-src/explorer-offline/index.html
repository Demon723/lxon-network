Block explorer — offline

This hostname used to serve the LXON block explorer. It no longer does, and the chain is not the reason. On 2026-11-03 the node that hosted it was lost and the chain was restarted on one small free-tier instance in AWS Stockholm running only the consensus client. The explorer is a separate stack — a database and several application containers — and that shape does not fit the host this chain now lives on.

What still works: chain 724 is live, sealing a block every five seconds, and readable through a public read-only RPC endpoint. You can verify the chain yourself without any explorer: 
curl -s -X POST -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_blockNumber","params":[]}' \
  https://rpc.lxon.in

The endpoint answers a fixed list of read methods and refuses every way of writing to the chain, including eth_sendRawTransaction. It is the same source the main site reads its figures from, so a number you get here and a number you see there cannot disagree.

Please note before you use any address: the chain restarted from an empty data volume. It kept its original genesis and its validator, but everything created between block 1 and block 242,493 is gone — tokens, contracts, the exchange pools and the bridge. An address from the old explorer is not a record of anything here.
